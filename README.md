How to run:

To run both of the programs, you need to have them in the same python project as the ‘sshtunnel’ file (from the template on Studium). The project needs to have the following packages intalled: pymysql, paramiko (run pip install pymysql paramiko in the terminal). Download the respective python file (show_department, product_discount) and put them into the project; let the scripts have the same name as the functions (you shouldn’t have to change any names after downloading).

To run show_department, open the terminal (ALT+F12 on windows in pycharm), enter ‘python show_department.py’ and then enter your Studium username and password in the (2) subsequent prompts. You will then be able to enter a department id of your choosing, for example 210000 (a leaf with products), or 100000 (non-leaf): note that the number must be entered without citation marks. 

To run product_discount, open the terminal (ALT+F12 on windows on pycharm), enter ‘python product_discount.py’ and then enter your Studium username and password. Then enter the ID of your desired product, for example Co67432 for ‘Computer bad’ or S867432 for ‘Big shoe’. The product's name as well as the discount in decimal will be printed and you will then be prompted to change the discount of the product: you can either enter y or n (note: type exactly y, or exactly n, otherwise you’ll be prompted to do so again). Typing n (as in no) will exit you out of the function. Typing y will ask you to update the discount. The domain of discount is 0 <= discount <= 1, values outside of that (or invalid data types) will cause an error message and exit you out of the database, making you rerun the function. After typing a valid discount (for example: 0.19 0.26 0.96 0 1) the function will once again show you the product with its – now updated – discount; it will then push the commit so that the change is stored in the database.
